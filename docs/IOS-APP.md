# Vaccine Talks — iOS / iPhone app

## Identifier

- **Bundle ID:** `com.vaccinetalks.app` (set in Xcode target → Signing & Capabilities)
- **Display name:** Vaccine Talks
- **Project path:** `ios/App/App.xcworkspace` or `ios/App/App.xcodeproj` (open the workspace if CocoaPods/SPM requires it; Capacitor 8 uses SPM plugins)

## Open in Xcode

1. Install Xcode from the Mac App Store.
2. Open `ios/App/App.xcodeproj` (or workspace generated by Capacitor).
3. Select the **App** target → **Signing & Capabilities**.

## Sync after Capacitor changes

```bash
npm run cap:sync:ios
```

## Simulator

1. Xcode → select an iPhone simulator.
2. **Product → Run**.

## Physical iPhone

Requires **Apple Developer Program** ($99/year) for device provisioning:

1. Add Apple ID in Xcode → Settings → Accounts.
2. Enable **Automatically manage signing** and select your Team.
3. Connect device; trust developer certificate on phone.

This preparation branch does **not** require a paid subscription to **inspect** the project; running on a **real device** does.

## Universal Links

- Entitlements template: `ios/App/App/App.entitlements` — replace `TEAMID` in hosted `apple-app-site-association`.
- Hosted: `https://www.vaccinetalks.com/.well-known/apple-app-site-association`
- Repo template: `public/.well-known/apple-app-site-association`

Enable **Associated Domains** capability in Xcode (`applinks:www.vaccinetalks.com`).

## Archive & TestFlight (future)
